## 6. Known limitations

What the evidence above does **not** show, and where the design is weaker than it looks.

1. **One real LLM episode.** n = 1 for `deepseek-flash` (plus one unscorable run). No pass@k, no variance across seeds or models; DeepSeek has no `seed` parameter, so episodes are not reproducible (the transcript is, via replay).
2. **Method compliance is instructed, not verified.** The task names Q-learning/SARSA/tile coding/DQN; the static checks enforce a module allowlist (numpy, gymnasium; torch only where allowed) and ban pickle/network/process/FFI imports, but do not prove *which* algorithm runs. E.g. dynamic programming on `env.unwrapped.P` would pass FrozenLake.
3. **Held-out env instances exist only for FrozenLake.** Taxi and CliffWalking are deterministic and use held-out seeds only: a hand-written optimal policy would pass there. Audit flags (not in the reward) point a reviewer at such submissions (ADR-0009 D).
4. **The process sandbox is not a security boundary.** rlimits, scrubbed env, process-group kill and static checks; no network or filesystem isolation at the OS level (ADR-0002). On this macOS host RLIMIT_AS was not enforced (from `limits_applied` in the reference trajectory); an RSS watchdog stands in. A container backend (`--network none`, read-only root) is the production answer behind the `Sandbox` interface.
5. **Red team covers known attacks on one task.** The adversaries target FrozenLake; unknown attacks and other tasks are covered only by the general layers (re-run, harness-owned evaluation, static checks).
6. **The report check is syntactic.** Bold numbers must match harness-logged dev means and cited runs must exist; the prose (method description, limitations) is not verified. The report term is 0.1 at most.
7. **Zero margin on cliffwalking-sarsa.** The reference reaches exactly the threshold; it is deterministic (pass rate 100 %), but any regression in the reference fails the task.
8. **Cost guard overshoots by up to one model call** (checked after each call); the 80 % warning makes reaching the cap rare. Prices for the cost estimate are list prices from ADR-0011, not billed amounts.
9. **Single machine, sequential episodes.** No parallel rollout workers, no resumable batch runs; the facade (ADR-0012) is the hook for an external rollout loop.
